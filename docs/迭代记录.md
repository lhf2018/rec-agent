## 2026-10-20 · v0.1.0 MVP 落地 + 首次推远程

### 背景

完成技术方案 v1.5 与架构评审后，按软件工程里程碑在空仓库落地可运行 MVP，并推送到 GitHub。

### 本轮完成

**设计文档**

- `技术方案.md` v1.5：资格与机会分离、可编码路由、Agent 增益验收、三臂评测
- `架构图.html`：跨团队表达版
- `架构评审-v1.5.md`：问题优先级与改法
- `待确认.md`：频控等假设参数

**工程实现**

- 单体包 `rec_agent/`：policy · engine · runtime · tools · service · api · store
- 种子数据：商家目录 + 六类演示用户
- Mock LLM：DIRECT / REACT 无需 API Key
- Guard：允许集、证据、事实对齐、同类目裁剪
- SQLite 任务 / 步骤 / 反馈；幂等建任务
- FastAPI + `web/index.html` 演示
- `pytest` 12 例；`eval/runner.py` 三臂 10/10

### 验证

```text
pytest -q          → 12 passed
python eval/runner.py → passed 10/total 10
  其中 conflict/react gain=true（短期面食优于引擎头名汉堡）
```

### 已知限制

- LLM 仅为确定性 mock，未接真实模型
- 负向偏好在进程内存中生效，TTL 未自动过期
- 频控/冷却等数字为可配置假设，见 `待确认.md`
- 机会判断未做学习型收益模型；`delay` 时机用 suppress 近似

### 下一步候选

1. 接入真实 Tool-Calling 模型（保留 mock 开关）
2. 负向偏好持久化 + TTL
3. Trace 面板增强（按步骤可视化）
4. 扩充离线用例与人工抽查清单
5. 小流量实验方案（有真实行为后再做）
